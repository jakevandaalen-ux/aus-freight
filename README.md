# Aus Freight

Roof Racks Galore's Australian freight map (same family as RRG-NZ-Freight).

- `index.html` – the map: every Australian delivery postcode coloured by Australia Post zone (Metro, Outer Metro, Regional) or ABS remoteness, plus the seven state warehouses.
- `data/` – postcode points (from github.com/matthewproctor/australianpostcodes), simplified state outlines (Natural Earth via world-geojson), warehouses.
- `scripts/` – page template and build script.
